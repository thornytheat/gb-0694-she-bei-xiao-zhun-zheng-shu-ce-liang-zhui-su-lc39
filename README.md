# 设备校准证书与测量追溯

检验机构质量员使用本工具完成：合并仪器使用与校准证书，裁决测量是否在有效可追溯链内。

## 业务

证书有效期与量程双约束；参考标准也须在校准时有效，证书撤销向下游传播并检测环。八个模块：证书接收、设备别名、有效区间、量程匹配、溯源链路、测量裁决、撤销复核、台账发布。模块独立API及页面入口见docs/API.md。样例中包含真实常见脏数据，原因码和原始行号在隔离面板及证据文件中可复核。

## 台账发布（M8）

每周全量证书批次在“台账发布”页发布为版本化设备台账。同机别名归并到一台设备；同机重叠证书与撤销记录一并参与判断。本批未出现的证书进入“缺失待核实”桶而不是直接下架，已撤销证书跨批粘性保留，过期按半开区间独立分桶——缺失、撤销、过期三类互不混用，每条记录保留设备归属与变化来源。

同内容批次（原文SHA256+规则版本+判定日）重跑只复用既有版本、不新增版本号；发布在单事务内完成，失败自动回滚、旧版指针不变，可随时在页面回滚到任一历史版本。试算接口`POST /api/m8`只核对不落库；证据CSV含分桶、变化来源与带行号的隔离行。样例按`ledger-week1→week2→week3`顺序发布即可核对完整变化链。

## 启动与验证

```sh
docker compose up --build -d
docker compose exec -T app pytest -q
docker compose config --quiet
```

打开 http://localhost:18208 。点击“运行样例”，或展开输入区提交CSV。切换七个模块查看计算依据。复核区可通过或退回，同一版本仅允许一次复核。证据CSV包含所有阶段与隔离行，批次内容不因复核变更。

SQLite保存在命名卷records；容器重建保留历史。只在确认不再需要数据时执行 `docker compose down -v` 重建。端口可通过.env中的PORT调整。本地也可 `pip install -r requirements.txt` 后 `python -m app.main`。

## 定义与限制

详见docs/DATA-DICTIONARY.md、docs/DEPTH.md。单文件最大5MB/一万行，本工具按确定性文件离线复算，不查询外部业务系统。源码位于app，测试位于tests，样例位于sample_data。
